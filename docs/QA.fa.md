# بررسی نسخهٔ ۰.۲

- ۱۵ تست Node پاس شدند: ۹ نتیجهٔ دوئل، تمام ۵۰۴ ترکیب کف/پشت برای جمع ۳ تا ۸ نفره، حذف تک، تکرار بدون تک، انتقال به دوئل یک‌مرحله‌ای، شمارش دورهای غیرمساوی، امتیاز و رکوردهای جدا، و محافظ‌های انتشار قالب.
- Chrome واقعی در حالت headless: مسابقهٔ کامل سه‌دوره، ذخیره و بازیابی پس از reload، انتخاب مخفی دو انسان، حذف تک، دوئل نهایی، توقف هنگام تایمر روشدن دست و ادامه، عرض دسکتاپ ۱۳۶۶ و موبایل ۳۹۰ بررسی شدند. تصاویر در out/qa تولید می‌شوند.
- npm run build موفق؛ خروجی وب بدون SDK یا درخواست به YouTube. npm run android:prepare موفق و مانیفست تولیدی portrait است.
- اولین اجرای GitHub Actions، APK دیباگ را با موفقیت ساخت؛ شکست اجرا در upload-artifact بود: سهمیهٔ ذخیرهٔ Artifacts حساب پر است. این شکست را نباید شکست کامپایل APK تلقی کرد، ولی فایل هنوز از آن اجرا تحویل نشده است.
- APK روی گوشی واقعی/شبیه‌ساز اجرا نشده؛ تست لمسی دستگاه واقعی و رضایت از ریتم دست‌ها باید پیش از انتشار نهایی انجام شود. پرداخت، تبلیغ، جدول آنلاین و گرافیک نهایی هنوز در محصول نیستند.
