# بازی آنلاین با Colyseus — سیستم و شبکهٔ داخلی

## اجرای ساده

روی کامپیوتر میزبان `START-ONLINE.cmd` را اجرا کنید. برای اولین نصب، قبلش یک بار `npm ci` لازم است. پنجرهٔ سرور باید باز بماند. معادل دستورات:

```powershell
npm ci
npm run build
npm run start:online
```

سرور، وب‌سایت بازی و Colyseus را روی یک پورت ۲۵۶۷ ارائه می‌کند. روی میزبان http://127.0.0.1:2567 را باز کنید. برای گوشی/کامپیوتر دوم، هر دو دستگاه به یک شبکه وصل شوند و یکی از آدرس‌های LAN چاپ‌شده توسط سرور را در مرورگر دستگاه دوم باز کنید؛ `127.0.0.1` روی گوشی به خود گوشی اشاره می‌کند.

نشانی نمونهٔ گوشی `http://192.168.1.10:2567` است؛ آن را با IP واقعی میزبان عوض کنید. با تغییر شبکه یا DHCP ممکن است IP عوض شود؛ خروجی سرور آدرس فعلی را نشان می‌دهد. اگر از گوشی باز نشد، شبکهٔ مهمان/جداسازی دستگاه‌ها یا دسترسی Node به شبکهٔ خصوصی در فایروال بررسی شود. هیچ قانون فایروال یا تنظیم شبکهٔ سیستم به‌طور خودکار تغییر نکرده است.

## ساخت و ورود به اتاق

۱. در لابی، سنگ کاغذ قیچی یا پلم پولوم پلیچ را انتخاب کنید؛ تعداد دورها/ظرفیت گروه را از «بازیکن‌ها و دورها» تعیین کنید.
۲. «بازی آنلاین با دوستان» را بزنید. نام خودتان را تغییر دهید یا نام پیش‌فرض را نگه دارید. در حالت عادی آدرس سرور خودکار از نشانی همین صفحه مشخص می‌شود.
۳. میزبان «ساخت اتاق با حالت انتخابی» را می‌زند. گزینهٔ «جای خالی با کامپیوتر» اختیاری است؛ روشن‌بودن آن باعث می‌شود هنگام شروع، ظرفیت خالی با بازیکنان کامپیوتری تکمیل شود.
۴. دوستان از دستگاه‌های خودشان همین صفحه را باز می‌کنند و با نام و کد هشت‌کاراکتری اتاق وارد می‌شوند. کدهای کوچک/بزرگ و ارقام فارسی هم پذیرفته می‌شوند. نام‌های تکراری با پسوند از هم جدا می‌شوند.
۵. همه «آماده‌ام» را می‌زنند؛ سپس میزبان شروع می‌کند. بدون کامپیوتر، حداقل دو نفر برای دوئل و سه نفر برای دورهمی لازم است.

## قواعد شبکه

- هر اتصال فقط برای بازیکن خودش انتخاب می‌فرستد. نتیجه، بردها، حذف و حرکت کامپیوتر را سرور محاسبه می‌کند.
- حرکت‌ها داخل حافظهٔ خصوصی اتاق‌اند؛ قبل از ثبت انتخاب همه، فقط وضعیت «دست ثبت شد» ارسال می‌شود، نه خود حرکت.
- اولین حرکت معتبر هر دست قفل می‌شود. پیام تکراری، دست قدیمی، حالت نامعتبر یا تلاش بازیکن حذف‌شده پذیرفته نمی‌شود.
- پس از روشدن، چهار ثانیه فرصت مشاهده هست و دست بعد خودکار آغاز می‌شود. در دوئل نهایی، تساوی تکرار می‌شود.
- برای انتخاب هر دست ۶۰ ثانیه فرصت وجود دارد. پایان مهلت، مسابقه را بدون برنده لغو می‌کند؛ سرور به‌جای بازیکن غایب حرکت تصادفی ثبت نمی‌کند.
- قطع موقت، جایگاه را ۳۰ ثانیه نگه می‌دارد و SDK برای اتصال مجدد تلاش می‌کند. پس از reload در همان تب/نشست، «بازیابی اتصال قبلی» قابل استفاده است؛ توکن فقط در sessionStorage مرورگر ذخیره می‌شود.
- خروج عمدی یا تمام‌شدن فرصت اتصال مجدد در جریان مسابقه، آن مسابقه را بدون ثبت نتیجه لغو می‌کند. اگر میزبان برود، اولین عضو باقی‌مانده میزبان می‌شود. هر مسابقه سقف ۲۵۰ دست دارد.
- نتایج اتاق آنلاین با رکورد محلی مخلوط نمی‌شوند. حساب کاربری، جدول جهانی و ذخیرهٔ دائمی سرور هنوز وجود ندارند. با خاموش‌شدن سرور، اتاق‌های درون حافظه از بین می‌روند.

## خروجی مستقل و Android

فایل `out/play.html` هنوز بازی محلی را بدون سرور اجرا می‌کند. برای بخش آنلاین آن، سرور Colyseus باید روشن باشد و آدرسش در پنجرهٔ اتصال وارد شود. برای تست گوشی در این مرحله، صفحهٔ LAN را در مرورگر گوشی باز کنید.

فایل‌های پروژهٔ Android با کد جدید همگام می‌شوند؛ APK جدید روی گوشی تست/منتشر نشده است. برای بستهٔ Android با سرور عمومی، `VITE_COLYSEUS_URL` را به نشانی HTTPS سرور تنظیم کنید و بیلد تازه بگیرید. اتصال HTTP شبکهٔ داخلی داخل WebView اندروید می‌تواند به تنظیم مخصوص دیباگِ cleartext/mixed-content نیاز داشته باشد؛ تنظیمات انتشار برای این تست تضعیف نشده‌اند.

## راه‌اندازی و محدودیت عملیاتی

طبق انتخاب کاربر، فقط سیستم/شبکهٔ داخلی هدف این مرحله است. میزبانی عمومی، تونل، دامنه، حساب پرداختی یا انتشار اینترنتی ایجاد نشده است. اتاق‌ها مهمان هستند و کد اتاق مجوز حساب کاربری محسوب نمی‌شود. برای اینترنت عمومی باید TLS، محدودسازی ایجاد اتاق/درخواست، سیاست سوءاستفاده، پایش و احراز هویت متناسب با محصول اضافه شوند.

Colyseus Core/SDK/WS نسخهٔ ۰.۱۸ استفاده شده است. peer dependency احراز هویت در درخت npm نصب می‌شود ولی مسیر OAuth/auth روی سرور این بازی فعال نشده است. بررسی npm هنگام پیاده‌سازی ۶ مورد low و ۳ مورد moderate در زنجیرهٔ وابستگی‌ها گزارش کرد؛ برای انتشار عمومی باید نسخه‌ها و این موارد دوباره ارزیابی شوند. این پروژه نمونهٔ LAN است، نه سرویس عمومی تأییدشده.

## تست‌ها

```powershell
npm test
npm run test:online
npm run test:browser
node scripts/test-online-browser.mjs
node scripts/test-standalone.mjs
```

تست واقعی هشت کلاینت Colyseus، محرمانگی حرکت، قفل‌بودن انتخاب، کنترل میزبان، قطع/وصل، حذف تک، دوئل نهایی، خروج و انتقال میزبانی پاس شده‌اند. Chrome با دو نشست مستقل، نام‌ها، ساخت/ورود، آمادگی، نتیجهٔ مشترک، reload/reconnect، بازی مجدد، انسان/کامپیوتر و میز آنلاین هشت‌نفره در عرض موبایل بررسی شده است. تصاویر در out/qa هستند. تست‌ها در مرورگر و کلاینت‌های شبیه‌ساز شبکه اجرا شدند؛ اتصال از یک گوشی واقعی روی Wi-Fi هنوز نیازمند تست کاربر است.
