# دوئل ترنج | Nostalgia Duel

دوئل ترنج بازی سنگ‌کاغذقیچی با نگارگری ایرانی است. سه حالت دارد: کلاسیک، دوئل پنج‌حرکتی و «پلم پولوم پلیچ» برای دورهمی. ساختهٔ [استودیو جولی پاندا](https://jollypanda.ir).

| نسخه | تجربه |
| --- | --- |
| وب | بازی با دوستان و جست‌وجوی سریع از طریق سرور Colyseus. سرور توسعه روی دستگاه میزبان یا شبکهٔ محلی اجرا می‌شود. |
| اندروید | بازی تک‌نفره با حریف‌های کامپیوتری، سه حالت بازی، آواتار و پیشرفت محلی. نسخه‌های بازار و مایکت خرید درون‌برنامه‌ای همان فروشگاه را دارند. |

رابط در وب و اندروید عمودی است و از فونت میخک ۳٫۱ با اعداد فارسی استفاده می‌کند. [مجوز فونت](public/licenses/Mikhak.txt)

## اجرا از سورس

به Node.js نسخهٔ ۲۲٫۱۲ یا جدیدتر نیاز است.

```sh
npm ci
npm run build
npm run start:online
```

بازی روی `http://127.0.0.1:2567` باز می‌شود. برای بازی از دستگاه دیگری در همان شبکه از IP دستگاه میزبان و پورت ۲۵۶۷ استفاده کنید. برای توسعهٔ رابط، `npm run dev` را هم در ترمینال جدا اجرا کنید. راه‌اندازی Colyseus و داده‌های محلی در [راهنمای سرور](docs/ONLINE.fa.md) شرح داده شده است.

## تست

```sh
npm test
npm run test:online
npm run test:browser
npm run test:online:browser
npm run test:viewport
```

چک‌لیست نصب و گیم‌پلی اندروید در [راهنمای بیلد و تست](docs/ANDROID-RELEASE.fa.md) است. آزمون مرورگری موبایل با Chrome روی ویندوز، هر سه حالت و مسیر خرید شبیه‌سازی‌شده را پوشش می‌دهد.

## اندروید

شناسهٔ اپ `com.jollypanda.nostalgiaduel` است. هر push به `main` بیلد و تگ نسخه را در [GitHub Releases](https://github.com/Jolly-Panda-Works/nostalgia-duel/releases) ایجاد می‌کند. برای تست روی گوشی APK دیباگ را نصب کنید. نسخه‌های بازار و مایکت پس از تنظیم امضا و کلید عمومی هر فروشگاه ساخته می‌شوند. [راهنمای بیلد و خرید](docs/ANDROID-RELEASE.fa.md)

## ساختار پروژه

- `src/` و `assets/` — رابط، قوانین و دارایی‌های تصویری بازی
- `online/` — اتاق‌های Colyseus، پروفایل و قابلیت‌های اجتماعی وب
- `scripts/` و `native/` — ساخت و تست اندروید و کد اتصال به فروشگاه‌ها
